Student Record Search System Using BST

Project Description: 
This project is a menu-driven Student Record Search System developed in C using a Bimary Search Tree (BST). It stores student enrolment IDs, names, and departments.
The project demonstrates BST insertion, searching, deletion, duplicate handling, tree traversals, and the effect of tree height on search efficiency.

Features:
1. Insert ten predefined sample student records.
2. Insert additional student records.
3. Reject duplicate enrolment IDs.
4. Search for student records.
5. Delete leaf nodes, one-child nodes, and two-child nodes.
6. Display records using inorder, preorder, and postorder traversal.
7. Display records in an asceding enrolment ID order.
8. Compare the height and search comparisons of two different BSTs.

Technologies  Used:
1. Programming language: C
2. Data  structure: Binary Search Tree
2. Concepts: Structures, pointers, recursion, and dynamic memory allocation.

How to run:
1. Open bst.c in a compiler.
2. Compile and run the program.
3. Select option 1 to insert ten sample records.
4. Select the required menu option to insert, search, delete, or display records.
5. Select option 8 to compare tree efficiency.

Complexity Aalysis:
For a regular BST, insertion, searching, and deletion take O(log n) time on average when the tree is reasonably balanced. Their worst-case time complexity is O(log n).
Tree traversal takes O(n) time.

Conclusion:
This project demonstrates student record management using a BST and shows how tree structure affects operation efficiency. It also explains why a self-balancing tree such as an AVL tree can improve worst-case performance.
